# Focus+ 🎯

FocusPlus is a web-based student productivity platform that helps learners stay focused, accountable, and engaged during study sessions. Using real-time webcam-based attention tracking, the platform monitors focus levels throughout study sessions and provides detailed performance insights. FocusPlus combines focus monitoring, collaborative study groups, progress analytics, and access to educational resources in a single environment designed to support effective learning habits.

## ✨ Features

### 👀 Real-Time Attention Tracking
- Webcam-powered focus monitoring
- Detects whether users remain attentive during study sessions
- Provides live feedback on focus levels

### 📊 Focus Analytics Dashboard
- View focus scores and study statistics
- Track concentration trends across sessions
- Analyze productivity patterns over time

### 👥 Study Groups
- Create and join collaborative study rooms
- Study alongside friends for accountability
- Encourage consistent learning through shared sessions

### 📚 Learning Resources
- Access educational materials from within the platform
- Organize useful study resources in one place
- Support independent and collaborative learning

### 📈 Progress Tracking
- Monitor study duration and session history
- Track improvements in focus and consistency
- Measure progress toward personal study goals

### 🔔 Accountability System
- Encourages users to remain engaged during study sessions
- Helps reduce distractions through active monitoring
- Supports the development of long-term study habits

### 🔒 Privacy & Security
- Secure user authentication
- Protected user data and session information
- Responsible handling of webcam-based focus metrics


## 🚀 Problem Statement

Many students and professionals struggle with procrastination, poor time management, and constant digital distractions. Existing productivity tools often lack personalization and actionable insights.

Focus+ addresses these challenges by combining inbuilt-webcam-driven guidance with task management and focus-enhancing features to help users achieve their goals more efficiently.

## 💡 Solution

Focus+ provides a centralized productivity ecosystem where users can:

1. Have access to wonderful learning resources (currently aimed at Grade 10)
2. Track progress over time.
3. Stay focused using structured work sessions through webcam-tracking
4. Build sustainable productivity habits.
